## Stabilisation criteria

We are stabilised by **[1000 ft AAL IMC / 500 ft AAL VMC]** with:

- On the correct lateral and vertical path
- On speed (Vapp -0 / +10)
- In landing configuration (gear down, flaps set)
- Thrust set (not idle unless briefed)
- Checklists complete

If not stabilised at the gate: **go-around, no discussion.**
